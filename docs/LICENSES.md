# Источники компонентов и отметки лицензий

Это перечень использованных компонентов, их карточек и файлов лицензий. Лицензия одной библиотеки не определяет автоматически права на модель, исходный текст, изображения или готовое видео. Для каждого медиа сохраняется собственная запись происхождения в проекте.

## Голоса

| Голос | Источник | Указание в карточке |
|---|---|---|
| `ru_RU-ruslan-medium` | [Piper MODEL_CARD](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/ruslan/medium/MODEL_CARD), [RUSLAN corpus](https://ruslan-corpus.github.io/) | Датасет: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) |
| `ru_RU-denis-medium` | [Piper MODEL_CARD](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD), [OHF voice datasets](https://github.com/OHF-Voice/voice-datasets) | Датасет: CC0 |
| `Silero v4_ru`, голос `aidar` | [Официальный каталог](https://github.com/snakers4/silero-models/blob/master/models.yml), [условия для моделей](https://github.com/snakers4/silero-models/blob/master/README.md#licence), [полный LICENSE](https://github.com/snakers4/silero-models/blob/master/LICENSE) | CC BY-NC-SA 4.0; модель не относится к исключению MIT для базовых CIS-моделей |

Для текущего личного пилота выбран Ruslan; работа рассматривается как некоммерческая. Ограничение NC из карточки не следует скрывать или заменять общей отметкой MIT репозитория. Для предполагаемого коммерческого применения голос нужно выбрать и проверить отдельно; Denis остаётся доступной технической альтернативой. Указание CC0 относится именно к описанному в карточке датасету и не заменяет проверку прочих материалов проекта.

Обе карточки сообщают дообучение от английского голоса `lessac medium`. Сценарий установки сохраняет исходные MODEL_CARD рядом с моделями и проверяет их SHA-256. Закреплённая ревизия загрузки: `c10ece1aade47bb51c153c893d14e5bf8e5b7117`.

Для нового некоммерческого ролика проверен дополнительный режим Silero. Авторство: Silero Team, Silero Models, Russian TTS `v4_ru`. Файл повторно использован из уже существовавшего локального кэша без скачивания модели; его хеш и происхождение находятся в `models/silero/manifest.json`, полный текст лицензии — в `models/silero/LICENSE`. Бейдж README сокращает название лицензии, но проверенный полный LICENSE включает ShareAlike. Модель не объявляется разрешённой для коммерческого использования.

Shotcut включает MLT, FFmpeg, Qt и другие компоненты со своими условиями. Их файлы лицензий и уведомления должны сохраняться вместе с исходным официальным комплектом. Загрузка отдельного инструмента по HTTPS и запись хеша не заменяют лицензионных документов. Здесь не предлагается удалять уведомления, переименовывать сторонние программы в собственные или объявлять весь комплект под одной лицензией.

Основные версии ядра закреплены в `pyproject.toml`, версии речевого окружения — в `requirements-tts.txt`. После явной установки pip записывается фактический список всех установленных пакетов. Текущий перечень не является исчерпывающим реестром всех транзитивных бинарных зависимостей.

## Материалы пилота и распространение

Название произведения и сведения о завязке используются в авторском аналитическом сценарии. Полный текст новеллы и архив кадров пользователем не предоставлены и в установщик не входят. Не следует присваивать им статус собственных или общественного достояния. При добавлении новых источников необходимо сохранять фактическое основание использования в реестре материалов.

Техническая возможность собрать ZIP не означает, что проверены условия публикации каждого нового набора материалов. Текущий результат предназначен для локального просмотра; публикация отдельно не выполняется. Для кода самой студии отдельный файл общей лицензии пока не выбран: этот перечень описывает сторонние компоненты, а не назначает проекту новую лицензию.
