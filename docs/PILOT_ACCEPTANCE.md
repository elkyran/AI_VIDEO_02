# Приёмка пилота 60–90 секунд

Живой видеопилот в текущем пакете BLOCKED. Симуляция 19 этапов — доказательство
управления состоянием, а не 60–90-секундное видео и не канонический анализ.
Тема и материалы нового живого пилота не выбирались автоматически.

До пилота нужны подтверждённые Gemini Story, Codex, Visual либо явный manual
с признанием неполной автономности, Scene import, runner, Drive и контрольный
video-review probe. Не использовать старый Gemini API key с просроченным
подтверждением Free Tier или неразрешённым расхождением модели.

Приёмка требует реальных WAV Ruslan, MLT, preview MP4, технического QA,
художественного review с фактическим coverage, одной целевой правки и проверки,
пересборки только затронутой сцены, remote dispatch, upload с hash/link и
restart/resume без дубликатов. Только владелец принимает художественный результат.

Измерять wall time, ручные действия, модельные calls, tokens (если доступны),
размер context pack, повторные чтения/сборки, дефекты, принятые секунды, visual
match, повторы и restart consistency. В отсутствие измерения — null, а не 0.
Сравнение старого/нового pipeline и принятые секунды пока null.
